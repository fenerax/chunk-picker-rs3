## Measurement method

The job script compares reference
`1d74791c65f36b39dfa360da87033ceed8ff9659` (merge of #103) with candidate
`a9e2cd27b744e529fc44df8e917b966a6387423a` (required main). The former is the
merge base, so this is a comparison of different calculator refs. Each fresh run
harvests public fixtures once, verifies identical input bytes and sends the same
serialized frames to both sides. Runs are sequential with inherited selectors
removed. No application file or comparison policy changed.

Limits match CI: 12 synthetic cases, 30000 ms per request, 720000 ms campaign,
780000 ms outer deadline, 768 MiB per bridge, 2048 MiB owned-group RSS.
The supervisor samples the entire owned process group every 50 ms; each bridge
also samples its RSS/VmHWM. This is sampled RSS, not a cgroup hard cap. Workers
retire at completion, so there is no persistent idle worker RSS measurement.
These are public CI workload measurements, not production pack/save timings.
