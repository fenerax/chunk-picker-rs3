## Inventory method and limits

Run `node scripts/perf/dead-code-inventory.mjs` (or `--json` for stdout JSON).
It reads tracked sources without importing app code or adding dependencies.
It deliberately over-retains basename collisions, comments, JSON strings,
aliases, namespace access, data tables and test/VM identifiers. Dynamic
expressions and template prefixes remain alive until inspected. Export
declarations/lists and CSS rule preludes are scanned lexically; this is not a
JS/CSS parser or proof of semantic reachability. Element/attribute/pseudo-only
selectors stay alive. Missing class/id tokens are manual review candidates,
including runtime-prefix and test references, never deletion instructions.
Untracked files are outside the scan until staged. The script excludes itself
so its reporting code cannot manufacture references.
