# Shantay Pass and Anachronia transport audit

Reviewed 2026-10-09 through the public RS3 RuneScape Wiki API, retrieving revision IDs and main-slot wikitext. Public search located the pages; OSRS results were excluded. No logged-in game, personal save, live picker, or observed journey was used. The main repository's existing component mask was opened read-only; all outputs were written in the `dataacc` worktree.

The absence of these journeys in the duo's F2P view has two causes: the carpet network and several Anachronia teleport methods were genuinely missing from the reviewed catalogue, while the Anachronia lodestone and ship were already catalogued. Every audited journey is members-only. The supplement repairs catalogue coverage while preserving F2P exclusion.

Four reversible carpet spokes and six global teleport records were added. The active catalogue is now 237 routes at 167 stations: 51 F2P and 186 members, with the same six pending routes and three unresolved destinations as the historical catalogue. The carpet supplement covers the requested Shantay destinations; it does not claim a complete nine-station carpet network. Other Anachronia methods, including Archaeology devices and additional item teleports, remain outside this bounded review.

Carpets use precise kind `carpet` in access evaluation and display kind `transport` with `routeKind:carpet` in the map connection payload. The versioned connection extension adds four drawable routes and six destinations while retaining every previous connection, walking edge, destination and provenance declaration unchanged. Members-only flags accompany every added display record. Existing pin-detail artifacts are unchanged; no nearby marker was joined by an assumed identity.

Ten of the eleven new exact Wiki anchors have exact decoded plane-0 component witnesses, with mask/runtime SHA-256, byte offsets and labels. The Player Lodge tablet coordinate has a source-plane mismatch and receives no witness. Runtime cache evaluation fails closed for that station; no neighbour or guessed landing was substituted. Operator points identify transport station access, not an observed player's landing tile.

The immutable October 8 catalogue, segments, map artifacts and hashed generators remain unchanged. `scripts/build-transport-supplement.mjs` deterministically creates `transport-routes.2026-10-09.v1.json` from the historical catalogue, `transport-routes.desert-anachronia.2026-10-09.v1.json` and the corresponding new component evidence, then creates `map-connections.2026-10-09.v1.json` from the historical v3 map artifact and supplement. Input text hashes use the repository LF hashing helper. The loaders select the new artifacts.

```powershell
node scripts/build-transport-supplement.mjs
node --test tests/transport-audit.test.mjs tests/transport-routes.test.mjs tests/transport-access.test.mjs
```

The new audit tests verify active input hashes and deterministic output, unchanged historical records, distinct Pollnivneach stations, current fare and southern quest gates, membership rejection despite fully supplied synthetic facts, independent personal requirements, exact component witness offsets, tablet failure, and ordinary connection payload coverage. Historical transport tests continue to reproduce their explicitly selected October 8 artifacts. Requirement tests use synthetic free unsplit geometry to isolate membership and facts; they are not proof of a real in-game trip. Full integration, browser filtering, save safety and performance verification are owned by the parent task.
