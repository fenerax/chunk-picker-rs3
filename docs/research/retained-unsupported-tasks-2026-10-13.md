# Retained unsupported task audit — 2026-10-13

The retained catalogue compiles exactly 34 unsupported rows before the H4 overlay. This audit reviews every identity, its direct skill gates, membership, original blocker and disposition. It uses the retained definitions and 31 dated public RuneScape Wiki revisions. It does not read either player’s private save or claim in-game verification.

Eighteen rows now have understood requirements. Sixteen retain unsupported hard gates and remain excluded from ordinary task presentation and source discovery. Thirty-three are members-only. The one F2P correction is ordinary cosmetic runecrafter robes, whose previous alias was missing and whose membership flag was wrong. No current unsupported row uses OutputVar.

The cosmetic robe alias now contains the twelve actual coloured variants sold in the retained Runecrafting Guild Rewards shop. It excludes the members-only Master outfit. RC50 remains the acquisition goal gate, although the Wiki describes no requirement to equip already-owned robes and a thaler acquisition alternative. This audit does not relax that level gate. Ironmen may buy the cosmetic robes from the Great Orb Project shop.
