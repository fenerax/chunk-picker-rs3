# Upstream dependency inventory, 13 October 2026

The application code can largely survive an independent rebuild, but the current application cannot start without upstream data. Its default startup reads the original chunk-info export and task-map seed; the rules interface also imports captured upstream wording. Replacing only `reference/original-picker/` would leave substantial upstream material in runtime catalogues, identity metadata, archives and tests.

The largest work is a new task and source catalogue: **20,375 task records in 34 categories**, backed by **2,556 chunk/area records**, **3,550 equipment rows**, **1,038 monster drop tables** and **404 shop inventories**. Existing cache and Wiki work supplies useful independent inputs, but is mostly an overlay or name join rather than a complete replacement. A smaller F2P release can avoid recreating the whole members catalogue.

Sizes are physical bytes in this checkout and parsed JSON entry counts. Decimal MB means 1,000,000 bytes. Counts overlap: a task label can occur in the definition export, seed, identity registry, correction records and reports. Never add these counts to estimate unique tasks. File groups below include their `.mjs` adapters unless separately identified. A source appearing in provenance alone does not establish that its entire dataset is copied.

“Independent source” means independent of Source Chunk. Cache/Jagex artwork and Wiki redistribution retain the separate publication conditions in the readiness report. Player 1 accepts credited Wiki adaptations under its CC BY-NC-SA terms; that does not make cache output or game art unrestricted. Local cache-export availability is documented by the existing extraction reports; this worktree contains no installed game-data bundle, and this job did not reverify those external files.

### Map identifiers and access joins

Distinguish four identifier systems:

- **Game regions:** ordinary surface IDs can be recomputed from game tile coordinates as `(floor(x / 64) << 8) | floor(y / 64)`. The current crop in `app/data/surface-grid.mjs` is 47 × 50 = 2,350 cells, with start ID 7495 and stride 256. Independently choose a crop and coordinate transform; the mathematical game region ID does not need an invented replacement.
- **Upstream selectors:** suffixes such as `12342-1`, `-0`, named interiors, chunk nicknames and alias lists are picker declarations. Rebuild boundaries from cache components and independently observed gates. A factual place name can be retained when independently sourced; do not copy the upstream grouping.
- **Our component IDs:** cache sections use suffix `1,000,000 + component label`. These are authored IDs over extracted collision data, but `legacyToComponents` and reverse aliases still connect them to upstream selectors. Keep collision facts; regenerate joins without upstream labels.
- **Saved map IDs:** `qxa` and `qxb` identify the duo's upstream maps. They are defaults at `app/capture-maps.mjs:12`, sync allowlist values at `app/core/state.mjs:176`, and fixture/document metadata. Remove hard-coded bindings from the public build; they do not require rebuilding world geometry. Source Chunk's Firebase URL is an optional service dependency, not an independent content source.

`cache-component-policy` contains 554 unique-boundary-signature mappings, 51 sole-component mappings, 80 object-spatial mappings, 4 reviewed-landmass mappings and **373 unresolved mappings**. This is why cache-only geometry is not already an upstream-free access model. Some fallback routes and task locations are admitted through retained declarations when exact correspondence is absent.

`app/data/map-corrections.mjs`, `access-policy.mjs`, `lodestones.mjs`, `cache-entry-policy.mjs` and `cache-surface-corrections.2026-10-08.v1.json` contain own overlays/observations. Keep independently evidenced tile coordinates, lodestone facts and membership decisions. Rebuild upstream-specific `oldValue`, section suffixes and reciprocal-boundary inferences; a link only to the retained export is not independent evidence. `app/data/world.mjs:11–14` even enables default cache walking by recognizing two upstream nicknames and a record-count threshold; replace that selection with an explicit new dataset capability.
